# AmpQuill

AmpQuill orchestrates real-time data processing through a scalable event-driven architecture, leveraging async messaging and auto-scaling node clusters.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/AmpQuill.git`
2. `cd AmpQuill`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
